# avigon.github.io

Personal portfolio site for Avinash Gondela, hosted on GitHub Pages.

Single-page, dependency-light: plain HTML, CSS (custom properties, no
Bootstrap/jQuery), and vanilla JavaScript.

## Sections

About · Journey · Education · Experience · Projects · Skills · Contact

## Features

- Dark/light theme, respects system preference, remembers your choice
- Scroll-spy navigation, reveal-on-scroll animations, filterable project grid
- Fully responsive, no build step required

## Local preview

```bash
python -m http.server 8000
# open http://localhost:8000
```

## Deployment

Pushes to the `master`/`main` branch are served automatically by GitHub Pages
at `https://avigon.github.io`.
